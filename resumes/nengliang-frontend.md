基于 qiankun 设计插件开放体系，支持不同技术栈应用接入主应用，并通过运行时 API 共享云盘上下文、文档操作、菜单唤起和自定义页面挂载能力。通过插件标准、SDK 和接入文档沉淀，将一次性定制需求转化为可复用的平台能力。

### 个性化门户与低代码首页

设计门户配置化方案，支持菜单、功能入口、页面背景、导航栏等个性化配置。实现首页画布、拖拽布局和组件注册机制，使系统内置组件与开放平台插件均可作为画布组件使用，减少重复定制开发。

针对 OA 系统大量复杂表单页面重复开发的问题，设计并封装基于 Ant Design 的配置化表单组件。组件支持动态表单、表单联动、校验规则和统一布局，OA 系统中大部分复杂表单页面均通过该组件实现，显著提升表单开发效率。

### AI 知识助手

实现面向 RAG 问答场景的流式 Markdown 渲染能力，支持结构化内容、代码高亮、表格、Mermaid 图表和数学公式渲染。针对频繁更新、长内容滚动和移动端渲染压力，完成增量渲染、异常兜底和性能优化。

### Electron 客户端架构升级

参与 Native 容器 + Web 业务层混合架构升级，设计 IPC 通信协议与本地能力桥接方式。处理 Electron 版本升级、Native 模块兼容、渲染进程沙箱、安全策略加固、启动性能和资源占用等技术难点。
