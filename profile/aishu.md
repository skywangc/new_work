### AnyShare企业智能内容管理平台 | Web 前端开发 | 2021.05-2023.06
- 从前端开关工程师晋升为前端团队负责人
- 获公司期权激励

企业智能内容管理平台是一个面向B端的私有化部署的，包含企业云盘、知识门户、AI知识助手为一体的系统。其前端主要技术栈包含：React、Node、Next.js、Nest.js、Elctron、NW.js。支持PC web端、H5端、以及基于Elctron的桌面客户端。

在此期间，我主要负责其前端开发工作，主要内容包括：
1. 基于NW.js + React实现一个Windows本地的应用程序，其做为AnyShare云盘客户端的子进程，配合云盘客户端实现云文档的属性、权限展示。以及分享、下载、搜索操作。
2. 维护基于Next.js实现的OAuth2.0协议的SSR统一登录项目，包含系统本地登录、第三方登录、SSO单点登录。
3. 维护基于Nest.js实现的一个前台业务聚合服务，包含文档共享连接、子系统登录等功能。
4. 维护基于React + TypeScript + webpack实现的AnyShare前端主应用、H5主应用。

### AnyShare企业智能内容管理平台 | 大客户端前端部门负责人 | 2023.06-至今
此期间从前端开发岗位晋升为前端团队负责人。主要职责为，负责AnyShare这个企业级 ToB 平台前端架构与团队治理，主导多端系统、Electron 客户端及 AI助手 工程化落地。

业务方面：
1. AnyShare前端主应用开放性能力建设：基于微前端技术，实现一套开放性标准，支持任意前端技术栈实现的应用可按照标准，做为插件接入主应用中，并给插件共享云盘运行时相关操作的API。
2. 将开放性技术复用到H5应用，并在H5主应用中实现中间层，将开放性技术带到AnyShare移动终端上，使AnyShare移动终端支持接入插件（小程序）的能力。

4. 在Web主应用实现个性化首页能力，借助低代码的思想，首页首页画布，管理员可根据需要自行调整画布上的组件，组件来自系统内置，以及任意实现了开放标准的插件。
