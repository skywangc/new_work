# 司空 Lite 三维态势可视化 Demo

这是一个用于面试讲解的前端演示项目，模拟大疆行业软件中的无人机三维态势看板。项目使用 Three.js 构建三维场景，用前端定时数据流模拟 WebSocket 遥测数据，包含无人机模型、航线、实时轨迹、告警、机群列表和点击选中交互。

## 运行方式

在仓库根目录启动本地 HTTP 服务：

```bash
python3 -m http.server 8000
```

访问：

```text
http://localhost:8000/demo/flighthub-lite/
```

## 面试讲法

可以把这个项目包装为“无人机作业态势可视化原型”。它不是完整的生产项目，而是用于验证三维地图、实时轨迹和前端性能方案的技术 Demo。

建议这样讲：

1. 业务目标：给调度人员提供一个三维态势界面，实时查看无人机位置、航线、任务状态、电量和告警。
2. 技术选型：原型阶段用 Three.js 快速验证三维渲染、拾取和轨迹更新；如果进入真实 GIS 场景，会用 Cesium 承载地理坐标、影像、地形和 3D Tiles。
3. 数据链路：真实项目中由 WebSocket 推送遥测数据，Demo 中用定时模拟数据流替代。前端按无人机 ID 归并最新状态，并用 requestAnimationFrame 合并渲染。
4. 渲染设计：无人机、航线和轨迹拆成不同图层。航线是静态 Line，轨迹是动态 BufferGeometry，避免每次更新都重新创建对象。
5. 性能考虑：限制轨迹点数量，复用 geometry/material，按帧批量更新，避免高频消息直接驱动 DOM 和三维对象频繁重建。
6. 交互设计：通过 Raycaster 做三维拾取，点击无人机后同步右侧设备详情，并把相机控制目标切到当前设备。

## 可以主动说明的边界

面试时不要把这个说成真实上线项目。更稳妥的表达是：

“我之前没有完整生产级 Cesium 项目经验，但为了准备这个方向，我做了一个 Three.js 的无人机态势原型。它帮助我把三维渲染、实时轨迹、对象拾取、状态归并和性能控制这条链路跑通了。真实上生产时，我会用 Cesium 处理地理空间能力，用 Three.js 或自定义 Primitive 处理更强的三维表现。”
